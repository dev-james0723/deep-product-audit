# QA and Release Verification

**Candidate: 4.0.0-rc.1**  
**Report date: November 21, 2026**  
**Status: implementation and local QA verified; publication receipt tracked separately**

The candidate passes its complete 231-test suite on Linux and macOS. Independent review reproduced and verified repairs for 11 additional implementation defects. Original assertions were preserved, fresh installation/uninstallation worked without third-party Python packages, and standalone known-defect demonstrations retained their clean controls.

These results establish the stated local scope. They do not establish Windows compatibility, independent upstream-product reproduction, hidden-benchmark performance or public release availability.

## 3. Eleven independently resolved findings

| ID | Reproduced defect | Verified repair |
|---|---|---|
| CORE-01 | All 27 held SQLite connections remained usable after fixture teardown. | Explicit connection closing; the unchanged lifecycle test verifies closed connections. |
| CORE-02 | Repeated findings inflated verified closures for one defect. | Count closures once per case and report duplicates separately. |
| CORE-03 | Changing an atomic fixture input did not change the claimed check digest. | Bind relevant fixture inputs, observation/scheduling helpers and timeout to the digest. |
| CORE-04 | Numeric `done: 1` was accepted as boolean terminal success. | Require the actual boolean `true`; reject non-boolean values. |
| CORE-05 | The batch oracle omitted missing requested records from its denominator. | Retain all requested IDs and validate unique, correctly typed child outcomes. |
| CORE-06 | Child output was truncated only after unbounded buffering. | Enforce a shared 64 KiB stdout/stderr capture limit while reading; fail closed on overflow/timeout. |
| PKG-01 | A removed grader directory escaped history screening. | Apply forbidden-path rules to each reachable commit. |
| PKG-02 | Blob deduplication concealed a historical forbidden filename. | Inspect historical paths before deduplicating content. |
| PKG-03 | Normal helper use generated bytecode that invalidated the installation receipt. | Prevent incidental bytecode from the helper import; ordinary CLI use remains verifiable. |
| PKG-04 | Uninstall removed an unowned empty directory. | Verify the complete owned directory set and refuse unexpected directories. |
| PKG-05 | A historical symlink was missed after the same path/blob became a regular file. | Include mode and kind in historical object identity. |

The reviewer reported no unresolved confirmed blocker **within the reviewed source scope**. This does not clear separate licensing, final-history or publication gates. The empty-test-selection runner now returns exit code 2, but the review does not claim a separately executed pre-fix failure for that change; it is not counted as a twelfth reproduced finding.

## 7. Reproduce the local checks

Run from a complete developer checkout with Python 3.10+ syntax support, standard-library SQLite and Git for Git-specific checks. The measured interpreter versions are those listed above; Python 3.10 execution itself remains untested.

Create a new output directory, then run:

```sh
python -B tools/run_tests.py
python scripts/benchmark_fixture.py --self-test --out ../qa-output/legacy-demo.json
python scripts/behavior_lab.py --out ../qa-output/behavior-demo.json
python scripts/network_fault_lab.py --mode compare --out ../qa-output/network-demo.json
python tools/package_skill.py --out ../qa-output/runtime.zip
python tools/install_skill.py install --destination ../qa-output/installed-skill
python tools/install_skill.py verify --destination ../qa-output/installed-skill
python tools/install_skill.py uninstall --destination ../qa-output/installed-skill
python tools/public_scan.py --history --out ../qa-output/public-scan.json
```

Use fresh output paths; helpers preserve existing evidence. Scan findings require review: the credential-rejection test's synthetic example URL is an expected reviewable match, not an actual leaked credential. Preserve its disposition instead of suppressing the test.
